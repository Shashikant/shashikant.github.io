\*\*Context:\*\* A reusable end-to-end framework to demonstrate UI and API automation on public practice apps (OrangeHRM and Restful-Booker).



\*\*My role:\*\* Architect and sole developer.



\*\*Approach\*\*

\- Playwright + Cucumber.js BDD with a custom World object to share auth tokens across step definitions.

\- Excel-driven test data to separate data from logic.

\- Resilient locators for complex Vue-based forms (label-relative XPath, custom dropdown handling).

\- Jenkins pipeline with published HTML reports.
