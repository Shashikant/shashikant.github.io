\*\*Goal:\*\* Reduce manual effort in writing tests, diagnosing failures, and logging defects.



\*\*Approach\*\*

\- Playwright with Page Object Model plus an LLM layer for failure analysis.

\- MCP-integrated test generation and healing workflow.

\- Automated Jira defect logging and Git workflow, configured through environment variables rather than hardcoded values.

\- Runs from VS Code and Jenkins.



\*\*Tools:\*\* Playwright, TypeScript, Anthropic SDK / Ollama, MCP, Jira, Jenkins



\*\*What I'd tell other QA leads:\*\* Use AI to draft and triage, and keep a human in the loop for sign-off.
